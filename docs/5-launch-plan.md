

# Go-To-Market & Launch Checklist

## Marketing & User Acquisition

* **Primary Launch Channel:** Instagram, acting schools, and theater communities. These channels can help us reach our first 50 users.

* **Value Proposition:** Find acting jobs easily and build your acting career with agent.

## Pre-Launch Deployment Checklist

- [ ] Check that all code changes are merged into the main branch.

- [ ] Test job searches and application forms.

- [ ] Check that actor profiles display correctly.

- [ ] Test the application on Chrome, Safari, and mobile devices.

## Launch Day Operations

- [ ] Publish the application using GitHub Pages.

- [ ] Check that the live website works correctly.

- [ ] Test the main features again.

- [ ] Share the application on Instagram and other acting communities.

- [ ] Collect feedback from the first users.
