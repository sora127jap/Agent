

# MVP Scope & Feature Backlog

## The Ultimate Product Vision

agent is an application that connects actors with acting jobs, from extras to main cast roles. It helps actors find jobs and helps casting directors find suitable talent quickly.

## The Launch Goal (v1.0 MVP)

To launch a functional version by **TBD**, focusing on the three most important features.

## Feature Prioritization Matrix

* **Must Have (MVP Lineup):**

  * `Job Search`: Actors can search and find available acting jobs. This is important because finding jobs is the main purpose of the app.

  * `Job Application`: Actors can apply for acting jobs directly through the app. This makes the job application process easier.

  * `Actor Profile`: Actors can create profiles with their information, photos, and acting experience. Casting directors can use these profiles to find actors.

* **Nice to Have (Post-Launch Backlog):**

  * `Evaluation System`: Casting directors can rate actors after jobs. This can be added later when more users join the app.

  * `Ranking System`: Actors can get rankings based on their experience and evaluations. This can be added after the evaluation system is ready.
